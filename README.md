# Plan Breakdown Skill

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

一个帮助用户将大目标拆解成分阶段执行计划的 Claude Code Skill，输出激动人心、可量化、可执行的阶段框架。

> **核心理念**：用行为学/心理学原理包装的拆计划流程，让"做计划"这件事从"打鸡血"变成"科学设计"

---

## ✨ 核心特性

### 🎯 三种时间颗粒度
- **短期计划（≤7天）**：横向 by-day 表格，每日主题+目标
- **中期计划（1-4周）**：横向 by-week 表格，每周主题+战役名
- **长期计划（1-3月+）**：纵向 by-stage 表格，阶段战役名+slogan

### 💪 抗失败设计
- **动作降级版**：满血版/精简版/5分钟保命版，应对状态波动
- **启动锚点**：每日第一个5分钟动作，零决策直接执行
- **每日3问闭环**：做到了什么/卡在哪里/明天第一步

### 🔬 专业感支撑
- **理论引用**：关键节点自动引用行为学/心理学理论出处
- **动机深挖**：3层递进问题挖出真正内驱力
- **高危场景识别**：多线并进，每个阶段都覆盖所有风险点

## 🚀 使用示例

### 示例1：7天求职冲刺计划

**用户输入**：
```
我想在7天内完成求职准备，包括简历优化、作品集整理、投递目标公司
```

**Skill 输出**：

```
📍 进度：[✅✅✅⏳⬜⬜⬜⬜⬜⬜⬜] 步骤4/11 - 动机深挖

让我先问你3个问题，挖出你的内驱力：

1. **表层 why**：你为什么想换工作？
```

*(后续按11步流程引导，最终输出横向by-day表格，每日有满血版/精简版/5分钟版动作)*

---

### 示例2：30天减重计划

**用户输入**：
```
我想在一个月内建立稳定的饮食和运动习惯，目标减重5斤
```

**Skill 输出**：

```
📍 进度：[✅✅✅✅✅✅✅⏳⬜⬜⬜] 步骤8/11 - 框架自评

【30天减重战役框架】自评：78分

阶段战役：
Week 1 - 环境重建周：清理冰箱+建立饮水习惯
Week 2 - 节律固化周：三餐时间锚点+睡前仪式
Week 3 - 运动启动周：每日5分钟拉伸+周末1次户外
Week 4 - 系统成型周：自动化饮食+运动进阶

高危场景覆盖：
- 线1（饮食失控）：每周都有"失控后补救动作"
- 线2（熬夜破坏代谢）：每周都有"21:30关机仪式"
- 线3（运动难启动）：Week 3开始用"5分钟保命版"

主要扣分项：Week 2的运动强度可能偏低，用户可能觉得"不够刺激"
```

## 📖 核心流程（11步）

1. **理解用户 + 识别高危场景**
2. **动机深挖**（3层递进问题）
3. **对齐理解**（确认目标、时间、约束）
4. **时间颗粒度确认**（短期/中期/长期）
5. **高危场景分线**（多线并进，不能丢）
6. **战役命名 + Slogan**（激动人心，峰终定律）
7. **输出框架表格**（策略层，只给策略名+KR）
8. **框架自评**（70分阈值，透明扣分项）
9. **用户确认**（是否需要调整）
10. **公开化承诺**（提高执行概率）
11. **战术层展开**（用户要求时才给具体动作）

详细流程见 [SKILL.md](./SKILL.md)

## 🎨 设计亮点

### 1. 进度可视化
每次回复顶部固定显示进度条：
```
📍 进度：[✅✅⏳⬜⬜⬜⬜⬜⬜⬜⬜] 步骤3/11 - 对齐理解
```

### 2. 自评再发
框架类输出必须先内部自评，达到70分阈值才发给用户。自评透明化：
```
我自评78分，主要扣分项：Week 2的运动强度可能偏低
```

### 3. 材料优先（严禁编造）
涉及用户材料优化时，必须先读材料再写示例。没数据就写客观描述，严禁编造数字。

### 4. 讨论颗粒度控制
制定计划过程中，细节讨论最多3轮就停，主动拉回主线："这个细节我们先记下来，等计划做完再回来展开"

### 5. 表格直接画
表格内容直接呈现在表格里，不要"给一个表+让用户问里面是什么"。用文本框线（┌─┬─┐）画清晰。

## 🧠 理论基础

本 Skill 基于以下行为学/心理学理论设计：

- **目标设定理论**（Locke & Latham）- SMART 原则学术源头
- **执行意图**（Peter Gollwitzer）- "if-then planning"
- **微习惯**（BJ Fogg, James Clear）- 小步前进，降低启动阻力
- **心流理论**（Csikszentmihalyi）- 挑战与能力匹配
- **自我决定理论**（Deci & Ryan）- 自主/胜任/归属三需求
- **峰终定律**（Kahneman）- 激动人心的战役命名
- **承诺一致性**（Cialdini）- 公开化承诺提高执行率

详细理论引用见 [SKILL.md](./SKILL.md)
